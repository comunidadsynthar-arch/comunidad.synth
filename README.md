# Synth Argentina ⚡🎛️🇦🇷

¡Bienvenido al repositorio de organización de **SYNTH ARGENTINA**! 

Este espacio está destinado a coordinar esfuerzos, documentar ideas, planificar la logística y, eventualmente, desarrollar la plataforma web o herramientas digitales necesarias para hacer realidad el primer gran encuentro de la cultura de sintetizadores en Argentina.

---

## 📂 Estructura del Proyecto

Proponemos la siguiente estructura inicial para organizar la información:

- [README.md](file:///c:/Users/54113/.gemini/antigravity/scratch/Proyecto%20comunidad%20Sinth/README.md): Este archivo, con la visión general del proyecto.
- [propuesta_inicial.md](file:///c:/Users/54113/.gemini/antigravity/scratch/Proyecto%20comunidad%20Sinth/propuesta_inicial.md): Detalle de la propuesta, pilares del evento y próximos pasos.
- `organizacion/`: Gestión del grupo organizador, minutas de reuniones y asignación de tareas.
- `locaciones/`: Opciones de lugares, costos, pros y contras.
- `expositores/`: Listado de fabricantes locales, marcas, tiendas y proyectos independientes a convocar.
- `programa/`: Propuestas de charlas, workshops, live sets y jams.
- `comunicacion/`: Estrategia de difusión, diseño, redes sociales y prensa.
- `presupuesto/`: Plantillas y números estimativos para viabilidad del evento.

---

## ⚡ Pilares de Synth Argentina

1. **Exposición y Demos**: Espacio para que fabricantes, tiendas y desarrolladores muestren sus equipos.
2. **Educación y Formación**: Charlas, clínicas y talleres (DIY, síntesis, producción, software).
3. **Música en Vivo**: Live sets, performances y jams comunitarias.
4. **Mercadillo de Equipos**: Sector de compra, venta y canje de sintetizadores y módulos.

---

## 🚀 Próximos Pasos (El Núcleo Organizador)

Para arrancar, necesitamos consolidar un grupo de **5 a 10 personas** para la primera reunión formal de organización, enfocada en:
1. Definir fecha y formato tentativo.
2. Evaluar opciones de locación.
3. Estimar un presupuesto inicial básico.
4. Diseñar la convocatoria inicial a expositores.
