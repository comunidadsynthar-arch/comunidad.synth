## Bloque 1: ¿Qué queremos que sea SYNTH ARGENTINA? 🎯
*Buscamos consensuar la misión, identidad y espíritu de la comunidad.*

### 1.1. ¿Cuál debería ser el corazón del proyecto en su concepción? *(Seleccioná hasta 2 opciones principales)*
- [ ] **Feria & Luthería Nacional**: Exposición de fabricantes locales de sintetizadores, pedales, módulos Eurorack y desarrolladores de tecnología sonora.
- [ ] **Espacio de Encuentro & Comunidad**: Conectar personas, mateada, intercambio de experiencias, compra/venta/canje de instrumentos usados y networking entre entusiastas.
- [ ] **Plataforma Formativa & Educativa**: Clínicas magistrales, talleres de diseño sonoro, charlas de ingeniería de circuitos y workshops DIY de armado.
- [ ] **Festival & Shows en Vivo**: Escenario con Live Sets, performances audiovisuales, experimentación analógica y jams colectivas.
- [ ] **Formato Integral Híbrido**: Una combinación equilibrada de feria comercial diurna + talleres + shows en vivo.

### 1.2. ¿Qué modelo de acceso y sostenibilidad económica preferís para el público general?
- ( ) **100% Gratuito y Abierto**: Financiamiento exclusivo mediante stands de marcas, sponsors y aportes voluntarios.
- ( ) **Entrada Popular y Accesible** (ej. equivalente a 1 o 2 cafés): Para cubrir costos fijos de locación y seguridad sin excluir a nadie.
- ( ) **Entrada Escalonada**: Entrada general básica libre/económica + arancel para talleres especializados o workshops con materiales incluidos.
- ( ) **Bono Contribución Voluntario**: Entrada libre con opción de colaborar para quienes deseen apoyar el sostenimiento del festival.

### 1.3. ¿Con qué frecuencia visualizás las actividades de Synth Argentina a futuro?
- ( ) Un gran evento anual insignia.
- ( ) Un gran evento anual + encuentros pequeños bimensuales (jams de sintes, meetups temáticos o ferias de usados).
- ( ) Ciclo continuo y descentralizado con actividades mensuales rotativas.

## Bloque 2: ¿Qué escala debería tener la primera edición? 📏
*Definir un alcance realista, lograble y con alta calidad para debutar con éxito.*

### 2.1. ¿Qué duración considerás ideal para el evento inaugural?
- ( ) **1 día intensivo (Recomendado)**: Sábado completo (ej. 12:00 a 22:00 hs). Permite concentrar toda la energía y minimizar costos de alquiler y seguridad.
- ( ) **2 días**: Sábado y Domingo (permite mayor cantidad de charlas y expositores, requiere mayor presupuesto y logística).
- ( ) **Jornada Doble Tarde/Noche**: Tarde de feria y clínicas + noche extendida de Live Sets / clubbing experimental.

### 2.2. ¿Qué tamaño de convocatoria deberíamos proyectar para la 1ª edición?
- ( ) **Escala Boutique / Íntima (150 a 300 personas)**: Foco en interacción cercana y nicho de sintetistas.
- ( ) **Escala Media (400 a 800 personas)**: Concurrencia amplia con espacio para circulación fluida.
- ( ) **Escala Masiva (1000+ personas)**: Convocatoria abierta e interdiscliplinaria en un predio de gran porte.

### 2.3. ¿Cuántos stands de marcas/fabricantes estimás adecuados para comenzar?
- ( ) 10 a 15 stands (los fabricantes clave de hardware y luthería nacional).
- ( ) 20 a 30 stands (marcas de sintes + pedales + disquerías + tiendas de audio + DIY).
- ( ) 35+ stands (sumando distribución de marcas importadas y escuelas de música).

### 2.4. ¿Qué tipo de espacio o locación te parece el más conveniente? *(Podés elegir más de una)*
- [ ] Centro Cultural autogestionado / Cooperativa artística con onda comunitaria.
- [ ] Centro Cultural público institucional (ej. C.C. Recoleta, C.C. Haroldo Conti, C.C. San Martín).
- [ ] Galpón industrial / Nave cultural con estética urbana.
- [ ] Ámbito universitario o terciario (ej. UNTREF, UBA FADU, etc.).
- [ ] Club de música en vivo / Sala de conciertos con infraestructura de sonido preinstalada.
- [ ] Espacio al aire libre con sector techado.
